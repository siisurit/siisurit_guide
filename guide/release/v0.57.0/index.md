# v0.57.0

## Improvements

Time series charts now contain gaps for periods without data as required by IBCS.

Narrow charts with only a few dates are now centered within the chart area instead of aligned to the right.

The project chart "Forecast for work needed to finish remaining tasks without estimate" now is a line chart instead of a stacked bar chart.

## Fixes

The task burn-up chart now shows even with estimates that have no date.

On the dashboard, the cards for active and recent tasks could contain duplicates.
