# v0.55.0

## Improvements

All charts include a short text explaining their purpose and how they can be used.
The chart member chart about "Deviation from estimate" is a lean vector image instead of a heavy plotly chart. This uses the available screen space more efficiently and loads faster.

The Clockodo connector uses the current API endpoints. Some of the older endpoints are scheduled for removal.

## Fixes

The translations for charts details are included now.
